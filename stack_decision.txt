Printing: Tauri print APIs + browser print for reports

date-fns or dayjs for calendars
recharts or tremor for simple analytics later
react-hot-toast or sonner for notifications
Electron is the alternative only if you need a very large existing plugin ecosystem. For your use case Tauri is superior.
Why not the other common options?
Electron + React: Still good, but heavier, slower startup, larger install size. Only choose this if your team already knows Electron well.
Flutter Desktop: Great UI, but steeper learning curve for web/API teams and less natural for your existing web-oriented API.
Pure web (Next.js / React) opened in browser: Loses real offline SQLite, proper desktop feel, system integration, and reliable QR/camera/print experience.
.NET / WPF / MAUI: Possible, but weaker modern UI ecosystem and slower development velocity for this type of app.
Splash Screen with Multiple Images (Easy with Tauri)You can create a dedicated splash window that:
